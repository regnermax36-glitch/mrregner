# maxregnerOS UI Guide

Complete guide to the maxregnerOS user interface.

## Overview

maxregnerOS features a completely redesigned UI that integrates seamlessly with One UI while adding unique maxregnerOS elements.

## UI Components

### 1. Settings Panel

**Location:** Settings → maxregnerOS

**Features:**
- **Liquid Reality** - Toggle reactive icons, no-grid workspace, true depth wallpapers
- **Cortex Integration** - Configure AI features, pre-emptive launching, neural notifications
- **Ghost Protocol** - Enable Data Mirage, Panic Grip, Kill Switch
- **Singularity** - Universal Remote and Desktop DNA settings

**Access:**
- Open Settings app
- Scroll to "maxregnerOS" section
- Configure individual features

### 2. Neural Notification View

**Location:** Notification Panel (pull down from top)

**Features:**
- Shows AI-generated summary instead of individual notifications
- maxregnerOS branding with accent color
- Updates every hour automatically
- Tap to expand full details

**Visual:**
```
┌─────────────────────────────┐
│ maxregnerOS                 │
│                             │
│ Mark asked about project... │
│ Mom wants dinner plans...   │
│ Package delivered...        │
└─────────────────────────────┘
```

### 3. Reactive Icons

**Location:** Home Screen Launcher

**Visual Feedback:**
- **Battery Low:** Icons dim and desaturate
- **Music Playing:** Music icon pulses to BPM
- **High CPU:** Gaming icons glow red

**Animation:**
- Smooth transitions
- GPU-accelerated
- Minimal battery impact

### 4. No-Grid Workspace

**Location:** Home Screen

**Features:**
- Apps float freely (no grid snapping)
- Tilt phone to slide apps to thumb
- Time-based app positioning
- Auto-float most-used apps

**Interaction:**
- Tilt left/right: Apps slide
- Tilt forward/back: Adjust depth
- Long press: Toggle gravity mode

### 5. True Depth Wallpapers

**Location:** Wallpaper Settings → maxregnerOS Wallpapers

**Features:**
- 3D parallax effect using gyroscope
- Head-tracking via front camera
- Creates depth illusion
- Multiple preset scenes

## Color Scheme

**Accent Color:** `#00FF88` (maxregnerOS Green)
**Primary Text:** White (#FFFFFF)
**Secondary Text:** Light Gray (#CCCCCC)
**Background:** Dark (One UI dark theme)

## Typography

- **Headers:** Roboto Bold, 20sp
- **Body:** Roboto Regular, 14sp
- **Captions:** Roboto Light, 12sp

## Icons

- **maxregnerOS Logo:** Hexagon with "M" in accent color
- **Feature Icons:** Custom-designed for each feature
- **Status Icons:** Animated indicators

## Animations

All animations follow maxregnerOS design principles:
- **Smooth:** 60fps minimum
- **Purposeful:** Every animation has meaning
- **Fast:** No unnecessary delays
- **GPU-accelerated:** Optimal performance

## Customization

Users can customize:
- Accent color (within maxregnerOS palette)
- Animation speed
- Feature toggles
- Notification summary interval
- Reactive icon sensitivity

## Accessibility

All UI elements support:
- High contrast mode
- Text scaling
- Screen readers
- Color inversion
- Reduced motion
